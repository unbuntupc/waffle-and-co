# Waffle&Co – Grenoble

Site vitrine de Waffle&Co (104 cours Jean Jaurès, 38000 Grenoble) : carte en carrousel, qui sommes-nous, contact et mini-jeu.

## Structure
- `index.html` : la page
- `style.css` : le style
- `script.js` : carrousel, formulaire et jeu
- `assets/` : logo et 3 pages de la carte

## Voir le site
Ouvre `index.html` dans un navigateur.

## Mettre en ligne (GitHub Pages)
Settings > Pages > Branch `main` / dossier `/ (root)` > Save.
